## Scope of this public release

This release ships the **local (in-process) document-processing path only**.
The remote-executor path and its RPC framework dependency are not part of this
release, so no additional third-party license is carried by it:

- documents are parsed, chunked, embedded and indexed by the backend's own
  worker pool, and answers retrieve from the resulting vector index;
- there is no document-executor node, no coordinator and no cross-service
  document protocol;
- the `knowledgeConfig.executionMode` setting accepts only the local mode; a
  configuration that still names a remote executor is refused at startup
  rather than silently downgraded.

## Third-party dependencies

`docs/THIRD-PARTY.md` is a machine-readable inventory, generated by
`tools/audit-licenses.ps1` from the resolved dependency graphs. For each Go
module and npm package it records the version actually selected and the
license that package declares.

That inventory is **not** a clearance. It reports what the packages state
about themselves, over the dependency graphs of this repository at the time
it was generated. A package's own declaration is not a licence review, the
inventory does not cover a dependency's own dependencies, and it does not
cover the licence of anything a user installs alongside this project. Anything
published under this licence should have its own check before release.

The most permissive licences among the resolved dependencies are BSD-3-Clause,
MIT and Apache-2.0; four entries are reported as "no LICENSE file at module
root" because their licence sits in the parent module directory, and the
inventory says so at the entry.
